# CoreHub

My developer portfolio site: live demos of all 20 apps, a CV viewer with PDF download, and a contact form.

## Planned features
- Home with hero and a filterable project grid (web/mobile, tech tags) driven by one typed `projects.ts` data file with live and GitHub links.
- Project detail pages with screenshots, stack, architecture deep-dive and "what to demo" bullets.
- CV page: on-screen viewer plus downloadable PDF, and an interactive skills matrix.

### Phase 2
- Contact form with spam protection
- Blog/case studies (MDX)
- Embedded live-demo iframes where allowed
- Analytics via a privacy-friendly free option

## Stack
Next.js (App Router), TypeScript strict, Tailwind CSS, Framer Motion, @react-pdf/renderer or print-styled CV page for PDF, Netlify Forms or a Netlify Function (email via a free provider) for contact, Netlify
